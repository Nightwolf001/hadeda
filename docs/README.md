## Direction in one paragraph

Flat, bold and sunny, in a 12-colour palette sampled from a Cape Town mural; "barely bit" pixel art (2 screen pixels per art pixel) for the hadeda and the scenery; Bricolage Grotesque, Hanken Grotesk and DM Mono for type, with lots of cream space. The interface moves on smooth curves; the game world steps like a sprite.

## Stages

Bo-Kaap (dawn) · Sea Point Prom (morning) · Table Mountain (midday) · Southern Suburbs (afternoon) · Muizenberg (golden hour) · Lion's Head (dusk). Defined in `packages/shared/src/stages.ts`.
